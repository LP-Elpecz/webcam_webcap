# webcam_webcap

一个不增加 Python 依赖的浏览器摄像头录像工具。Python 标准库只负责提供本地网页；摄像头取流、变焦、录像编码和本地保存都在浏览器内完成，视频不会上传到服务器。

## 功能

- 枚举并切换浏览器可见的摄像头；
- 选择 1080p、720p 或 480p，以及常用帧率；
- 提供“驱动变焦”和“软件变焦”两种方式；
- 实时预览当前最终录像画面；
- 使用浏览器 `MediaRecorder` 录像，停止后可回放确认；
- 页面加载时立即检测录像格式：优先保存 MP4，浏览器不支持时明确显示并使用 WebM；
- 支持系统文件选择窗口，旧浏览器则回退为普通下载；
- 页面关闭时停止视频轨道并释放摄像头。

## 启动

直接双击：

```text
run_webcam.cmd
```

该脚本复用 `AI-SOP-DEMO` 的 Conda 环境：

```powershell
conda run --no-capture-output -n ai-sop-demo python server.py
```

也可以使用任意 Python 3.11 解释器，因为服务端仅使用标准库：

```powershell
python server.py
```

默认自动打开 `http://127.0.0.1:8765/`。按 `Ctrl+C` 停止服务。

建议使用新版 Chrome 或 Edge。浏览器只允许安全来源使用摄像头，本机 `localhost/127.0.0.1` 属于特例；如果把服务开放给局域网其他电脑使用，需要额外配置 HTTPS。

## 两种变焦的区别

### 驱动变焦

网页通过视频轨道的 `getCapabilities().zoom` 获取摄像头公开的倍率范围，再调用 `applyConstraints()` 设置倍率。这条路径会真正调用浏览器和摄像头驱动公开的标准控制能力，不做画面 CSS 放大。

即使摄像头本身支持变焦，浏览器或驱动也可能不公开该能力。此时页面会显示“不支持”，应切换到软件变焦。浏览器还可能单独询问 PTZ/变焦权限。

### 软件变焦

网页将原始视频帧绘制到 Canvas，并按倍率进行中心裁切和放大。最终使用 `canvas.captureStream()` 录像，因此保存的视频会真正包含软件放大效果，而不只是网页预览变大。范围为 `1.0×`～`4.0×`。

切换到软件变焦时，程序会把驱动倍率恢复到 `1.0×`；如果设备的最小值不是 1，则恢复到其最小倍率，避免两种变焦叠加。

## 保存格式

程序根据浏览器可用编码器选择格式：

1. H.264 MP4；
2. VP9/VP8 WebM；
3. 浏览器默认格式。

停止录像后点击“保存录像到本地”。支持 File System Access API 的浏览器会弹出文件位置选择窗口，否则保存到浏览器默认下载目录。

录像停止前，数据保存在浏览器内存中。录制时间很长或使用较高分辨率时，应留意内存占用。

## 常见问题

- **权限被拒绝**：点击地址栏左侧的摄像头权限图标，重新允许后刷新页面。
- **摄像头被占用**：先关闭 MVS、会议软件或其他使用该设备的页面。
- **没有驱动变焦**：选择“软件变焦”；这表示浏览器没有获得 `zoom` 能力，不代表厂商客户端一定不支持变焦。
- **画面分辨率没有达到选择值**：网页使用的是优先值，摄像头会回退到自己支持的最接近规格。
- **网页从其他电脑打不开摄像头**：局域网 HTTP 地址不是浏览器认可的安全来源，需要 HTTPS。

## 测试

```powershell
python -m unittest discover -s tests -v
```

测试只使用 Python 标准库，覆盖静态服务、安全响应头、驱动变焦调用、软件变焦录像链路和本地保存入口。
